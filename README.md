# Virtuālā izstāde – Mūzikas vēsture

## 1. Projekta apraksts

Projekts ir izstrādāts praktisko mācību laikā, izmantojot HTML5, CSS3 un JavaScript.

**Projekta mērķis** ir izveidot interaktīvu, responsīvu un lietotājam ērtu tīmekļa vietni, kas ļauj iepazīt mūzikas vēstures attīstību no renesanses līdz mūsdienām.

Izstādē apkopota informācija par pieciem mūzikas vēstures laikmetiem, to raksturīgākajām iezīmēm, ievērojamiem komponistiem un skaņdarbiem. Apmeklētāji var apskatīt attēlu galeriju, noklausīties skaņdarbus un izmantot interaktīvu komponistu karuseli.

- **Izstādes tēma:** Mūzikas vēsture
- **Izstādes nosaukums:** Mūzikas vēsture – No renesanses līdz mūsdienām

## 4. Izmantotās tehnoloģijas

- **HTML5** – tīmekļa vietnes semantiskās struktūras, sadaļu, tabulas un audio atskaņotāju izveidei.
- **CSS3** – vizuālajam noformējumam, Box Model, Flexbox, Grid un responsīvajam dizainam.
- **JavaScript** – interaktīvas navigācijas, galerijas Accordion un komponistu karuseļa funkcionalitātei.
- **Git un GitHub** – versiju kontrolei un komandas sadarbībai.
- **Visual Studio Code** – projekta izstrādei un koda rediģēšanai.

## 5. Tīmekļa vietnes funkcionalitāte

Izstrādātajā tīmekļa vietnē ir:

- **Galvene (Header)** – navigācijas izvēlne ar saitēm uz vietnes sadaļām un mobilajām ierīcēm pielāgota izvēlne.
- **Galvenā sadaļa (Hero)** – izstādes virsraksts, apraksts, attēls un navigācijas poga.
- **Informācija par izstādi (About)** – izstādes tēmas un mūzikas vēstures laikmetu apraksts.
- **Attēlu galerija (Gallery)** – 10 attēli par pieciem mūzikas vēstures laikmetiem ar izvēršamiem informatīvajiem aprakstiem.
- **Audio sadaļa** – HTML tabula ar piecu mūzikas laikmetu skaņdarbiem un audio atskaņotājiem.
- **Komponistu karuselis (Carousel)** – piecu ievērojamu komponistu attēli un informācija ar manuālu un automātisku pārslēgšanu ik pēc 5 sekundēm, kā arī iespēju apturēt un atsākt pārslēgšanu.
- **Responsīvs dizains** – vietnes pielāgojums datoriem, planšetdatoriem un mobilajiem tālruņiem.
- **Kājene (Footer)** – informācija par projekta autoriem un saite uz GitHub repozitoriju.

## 6. Projekta palaišana

1. Lejupielādējiet projekta ZIP arhīvu no GitHub vai klonējiet repozitoriju:

   ```bash
   git clone https://github.com/rihards-tech/Fridrihsons_Riklans_P25-2_VirtualaIzstade.git
   ```

2. Atveriet projekta mapi.
3. Atveriet failu `index.html` tīmekļa pārlūkprogrammā.
4. Pārbaudiet vietnes navigāciju, galeriju, audio atskaņotājus un komponistu karuseli.

Projekta darbībai nav nepieciešama papildu bibliotēku vai programmatūras pakotņu instalēšana.
